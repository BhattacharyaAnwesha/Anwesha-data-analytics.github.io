# Dataset Description

The dataset used in this project contains Amazon sales records including:

- Order details
- Product categories (Furniture, Office Supplies, Technology)
- Sales, profit, and quantity
- Shipping modes (Standard Class, Second Class, First Class, Same Day)
- Geographic data (Country, City, Market)

The dataset provides a comprehensive view of sales transactions, enabling multi-dimensional analysis.

Data cleaning and transformation were performed before visualization to ensure accuracy and consistency.
