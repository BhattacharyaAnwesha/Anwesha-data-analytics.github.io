# Introduction

This project presents an analysis of Amazon sales data using Microsoft Power BI.

The goal of this report is to understand sales performance, customer behavior, and key business trends across different regions, categories, and shipping modes.

The dashboard provides an interactive view of:
- Sales and profit metrics
- Category-wise performance
- Market and regional distribution
- Shipping trends

This project demonstrates the use of data visualization techniques to convert raw data into meaningful business insights.
